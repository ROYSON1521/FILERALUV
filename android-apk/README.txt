FILERALUV Android APK

Install this file on an Android phone:
  fileraluv.apk

This is the debug APK for testing and personal installation. It includes the FILERALUV launch animation and is renamed from the Gradle output. The Android source project remains in the mobile folder. Build again there after changing the frontend or Android code.

Do not install app-debug-androidTest.apk; that file is for automated testing.
